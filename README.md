# Stillform

A full-stack fashion e-commerce platform built with React, TypeScript, Flask, and PostgreSQL, with a focus on responsive UI design, reusable frontend components, and maintainable application architecture.

## Overview

Stillform is a fashion e-commerce web application designed to deliver a clean, intuitive, and visually consistent shopping experience.

The project includes a customer-facing storefront and an administrative dashboard for managing products, inventory, categories, and orders. The frontend is the primary development focus, supported by a Python backend and a PostgreSQL relational database.

The interface is based on a Figma UI design reference that will be adapted into a functional web application.
